## 🔍 About

RDY7D3R is a Python-based OSINT toolkit designed to organize publicly available information research into one terminal interface.

The project provides a structured collection of lookup utilities for researching public information, validating data formats, and checking publicly accessible sources.

## ✨ Features

| Module | Description |
|---|---|
| Phone Number | Number format validation and public information |
| Email | Email syntax validation and domain information |
| Aadhaar | Format validation and privacy-safe information |
| PAN | Format validation and general document information |
| Vehicle / RTO | Public vehicle information resources |
| IFSC | Bank branch and IFSC information |
| IP Information | Public IP address information |
| Domain Lookup | Public domain and DNS information |
| Username | Public profile and username research |
| Search Engine | Public-source information discovery |
